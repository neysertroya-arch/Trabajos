# Anonymous replication package

This package accompanies the double-anonymized manuscript prepared for *Journal of Rural Studies*.

## Data sources

The analytical pipeline downloads or uses publicly available data from:

- Food and Agriculture Organization of the United Nations (FAO), structural data from agricultural censuses / World Census of Agriculture.
- U.S. Department of Agriculture, Economic Research Service (USDA ERS), International Agricultural Productivity data product.
- World Bank, World Development Indicators.

The manuscript does not compare TFP index levels across countries. It constructs annualized log changes from the USDA ERS country-specific TFP series.

## Reproduction order

Run the R scripts in numerical order through `R/08_publication_outputs.R`. Journal-facing scripts numbered after that stage do not alter the approved analytical estimates.

## Expected publication outputs

`outputs/publication/` contains the tables, figures, and machine-readable outputs generated by the approved pipeline.

## Blind-review handling

No author names, affiliations, ORCID identifiers, repository owner names, acknowledgements, or author contact details are intentionally included in this replication package. A permanent public archival location for code and derived data will be added in accordance with the journal's research-data requirements while preserving double-anonymized review.
