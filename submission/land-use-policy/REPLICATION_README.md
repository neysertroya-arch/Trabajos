# Anonymous replication package

This package accompanies the double-anonymized manuscript submitted to *Land Use Policy*.

## Data sources

The analytical pipeline downloads or uses publicly available data from:

- Food and Agriculture Organization of the United Nations (FAO), structural data from agricultural censuses / World Census of Agriculture.
- U.S. Department of Agriculture, Economic Research Service (USDA ERS), International Agricultural Productivity data product.
- World Bank, World Development Indicators.

The manuscript does not compare TFP index levels across countries. It constructs annualized log changes from the USDA ERS country-specific TFP series.

## Reproduction order

Run the R scripts in numerical order through `R/08_publication_outputs.R`:

1. `R/01_download_wcad.R`
2. `R/02_audit_wcad.R`
3. `R/02b_audit_wcad_comparability.R`
4. `R/03_download_usda.R`
5. `R/04_harmonize.R`
6. `R/04b_audit_farm_structure.R`
7. `R/04c_add_development_controls.R`
8. `R/05_descriptive_diagnostics.R`
9. `R/06_models_robustness.R`
10. `R/07_advanced_robustness.R`
11. `R/08_publication_outputs.R`

Supporting R files in the `R/` directory are part of the same pipeline. The included dependency lockfile should be used where supported to reconstruct package dependencies.

## Expected publication outputs

`outputs/publication/` contains the tables, figures, and machine-readable outputs generated by the approved pipeline. The submission workflow rebuilds these outputs before producing the anonymous manuscript.

## Blind-review handling

No author names, affiliations, ORCID identifiers, repository owner names, acknowledgements, or author contact details are intentionally included in this replication package. The permanent public archival location for code and derived data will be added to the accepted manuscript, subject to journal requirements.
